# TEST-01 — W5100 raw SPI probe: PASS

Date: 2026-10-09. Hardware: Arduino UNO + blue WIZnet W5100 Ethernet Shield, no microSD. Port COM4, serial 115200, SPI 1 MHz, W5100 CS D10, SD CS D4 disabled.

User-supplied serial output (startup noise omitted):

```text
KON LAB W5100 TEST-01 / SPI 1MHz / CS D10 / SD OFF
MR=0x00
RTR original=0x07D0
RTR test=0x1234
Restore=OK
RESULT: PASS / W5100 SPI READ WRITE OK
```

**Conclusion:** W5100 SPI register read/write and restoration passed on this sample. Does not yet certify Ethernet PHY, cable link, DHCP, TCP/IP, or SD. The startup garbled characters before the banner were observed but are not part of the register test.
