# Решение по SD и Ethernet — 11 октября 2026

**Диагностика SD и совместной работы SD + W5100 на этом экземпляре остановлена по решению оператора. Дальнейшая работа — Ethernet с физически извлечённой microSD.**

Причина отказа совместной работы не установлена. Подтверждённого исправления нет.
Предположение о физическом конфликте SPI или сборке shield остаётся гипотезой.
Изменения порядка вызовов и условий запуска не дали достаточного основания
для окончательного вывода. Новые варианты SD-диагностики, частот и подготовки
питания в текущий план не входят.

## Возврат к Ethernet

На момент решения загружен диагностический DETECTION TRACE. Для сетевой работы
следует вернуть обычную прошивку TEST-07 v0.2 из текущей ветки
`feature/w5100-test09-ethernet-sd`. В ней SD не инициализируется, CS D4 остаётся HIGH.
Карту извлекают при полном отключении питания UNO/shield.

Из корня репозитория, PowerShell 7:

```powershell
$null = Read-Host 'Отключи всё питание UNO/Shield. Извлеки microSD. Ethernet-кабель оставь подключённым. Затем нажми Enter'
$null = Read-Host 'Подключи USB UNO. Монитор Arduino должен быть закрыт. Затем нажми Enter'
$test = '.\labs\01-W5100-Ethernet\TEST-07_Network_Robustness'
& "$test\Build-Test07.ps1" -UploadPort COM4
```

Сборка и загрузка не дают аппаратного PASS. Новое наблюдение Ethernet после
возврата прошивки ещё не получено. Когда сетевые испытания возобновятся,
его результат следует фиксировать отдельно.

TEST-07 сохраняет шесть исторических сценариев PASS. DhcpOutage отложен до
отдельного изолированного роутера: PC по Wi-Fi, UNO по Ethernet. Домашняя сеть
для него не используется. Общий FULL PASS 7/7 не объявлен.
