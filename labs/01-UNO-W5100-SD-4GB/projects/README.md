# LAB-01 Practical Projects

This directory is reserved for practical applications built only after the
bring-up sequence passes.

Planned progression:

1. Minimal HTTP status server
2. Web page stored on SD
3. SD file browser over Ethernet
4. Network data logger
5. Sensor telemetry node
6. Configurable local control endpoint

Each project should have its own folder, README, sketch and test result.
