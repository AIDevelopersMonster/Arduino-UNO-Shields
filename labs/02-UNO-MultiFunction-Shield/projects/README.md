# LAB-02 future projects

Practical projects begin only after Stage A hardware certification.

Candidate directions:

- compact timer / countdown;
- counter with physical controls;
- voltage / analog-level indicator;
- menu-driven status panel;
- IR remote receiver;
- LM35 / DS18B20 thermometer;
- serial-module demonstration;
- simple alarm / annunciator;
- small teaching HMI using LEDs, buttons, buzzer and 4-digit display.

The first repository milestone is diagnostics, not feature count.
