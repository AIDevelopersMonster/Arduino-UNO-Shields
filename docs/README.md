## Documentation policy

A hardware or software capability is marked PASS only after a reproducible
physical test. Family documentation, proposed wiring, future interfaces and
architectural ideas remain explicitly labeled as references or design proposals
until tested.

Measured build values, runtime free-RAM readings, error/drop counters and
bounded non-claims are preserved in the corresponding test records.
