# Arduino UNO Compatible Board

This directory contains identification notes, photographs, pin information, power checks and laboratory tests for the Arduino UNO compatible board used in this project.

**Status:** legacy reference hardware / maintenance-only. The board remains useful for reproducing existing tests and for small auxiliary tasks; it is not the preferred platform for new primary development in this repository.

## Historical / optional checks

- MCU and USB interface identification
- 5 V and 3.3 V power rails
- USB programming
- UART loopback / serial communication
- digital GPIO
- analog inputs
- SPI compatibility with shields
- power-source behaviour and limits
